Start counting in one request.

Choose a namespace and a key, then hit a URL to create your counter. Read its value with another request, or explore every route and parameter in Swagger.

Open Swagger ↗ Try the demo

Start here

Enough to make the first request.

Use a namespace to group counters and a key to identify one event.

Increment a counter

Available

The first hit creates the public counter. Later hits increment it by one.

GET /hit/{namespace}/{key}

Read its value

Available

Read the current value without changing the counter.

GET /get/{namespace}/{key}

Create a managed counter

Available

Create a counter you can later set, reset, or delete. Save the admin_key returned in the response.

POST /create/{namespace}/{key}
