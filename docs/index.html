01 / Quickstart

One request is all it takes.

A hit creates the counter when it does not exist, increments it by one, and returns the new value.

$ curl https://suanpan.example.com/hit/acme.dev/homepage

# 200 OK
{ "value": 1 }
i
Choose a stable namespace. Your domain is a good default—something like acme.dev. Keys name the thing you are counting, such as homepage or signup-clicks.
02 / Core concepts

Small surface. Clear rules.

01

Namespace + key

Every counter lives at one pair. Both parts are 3–64 characters and may contain letters, numbers, _, -, or ..

02

Genuine counters

Counters born from a /hit are genuine: simple, unmanaged, and intentionally without an admin key.

03

Managed counters

Create a counter explicitly to receive an admin key. That key unlocks update, set, reset, and delete operations.

03 / API reference

Hit a counter

Increment by one. If the counter does not exist yet, Suanpan creates a genuine counter and returns 1.

GET /hit/{namespace}/{key}
namespacepath · string · required

A stable bucket for related counters.

keypath · string · required

The specific event or value you are counting.

Response200
{
  "value": 42
}
04 / Read

Read a counter

Fetch the current value without changing it, or request metadata when you need more context.

GET /get/{namespace}/{key}

Returns { "value": 42 }, or 404 when the key is not found.

GET /info/{namespace}/{key}

Returns the value, internal key, remaining TTL, existence state, and whether the counter is genuine.

{ "value": 42, "full_key": "K:acme.dev:homepage", "is_genuine": true, "expires_in": 14515199, "exists": true }
05 / Create

Create a managed counter

Use /create when you need to change, reset, or delete a counter later. The response includes its admin key.

POST /create/{namespace}/{key}
initializerquery · integer · optional

Starting value. Defaults to 0.

admin_tokenquery · string · optional

Supply your own token or let Suanpan generate one.

Response201
{
  "namespace": "acme.dev",
  "key": "signups",
  "value": 0,
  "admin_key": "••••••••"
}
!
Store the admin key when it is returned. It is the credential for privileged operations and should never be committed to client-side code or a public repository.
POST /create

Creates a managed counter with a random 16-character namespace and key. Useful when you do not need human-readable URLs.

06 / Manage

Change a managed counter

Send the admin key as Authorization: Bearer <key> or with the ?token= query parameter.

MethodPathEffect
POST/update/{namespace}/{key}?value=N

Add or subtract an integer.

POST/set/{namespace}/{key}?value=N

Replace the current value.

POST/reset/{namespace}/{key}

Return the value to zero.

POST/delete/{namespace}/{key}

Delete the counter permanently.

Update by five
$ curl -X POST \
  -H "Authorization: Bearer $SUANPAN_ADMIN_KEY" \
  "https://suanpan.example.com/update/acme.dev/signups?value=5"
07 / SVG shields

Turn any counter into a badge.

Append /shield to either read or hit endpoint. The hit variant disables caching so each image request is counted.

08 / Utility routes

Service information

GET/healthcheck

Checks API and Valkey connectivity. /health is an alias.

GET/stats

Returns key count, Valkey version, expired keys, and processed commands.

09 / Errors

Predictable status codes

400Bad request

Invalid key format, value, shield option, or an admin action on a genuine counter.

401Unauthorized

The supplied admin key does not match.

404Not found

The route or requested counter does not exist.

409Conflict

A counter already exists, or a managed operation cannot be completed.

10 / Limits & expiry

Designed to stay small.

characters per segment

Expiry~6mo

rolling TTL after every hit

Storageint

up to the platform safe maximum

A counter expires after roughly six months without a hit. Reading it does not refresh the TTL; hitting it does.
